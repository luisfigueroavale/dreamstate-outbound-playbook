# Settings

These files are the blank or working-default copies. Copy the folder to `settings.local/` and fill that copy. The copy is git-ignored.

Stop when a file you need says `Status: blank`.

`tiers.json` and `stack-rules.json` ship as working defaults so a local demo can run. They are still yours to change after a learning note. `team.json`, `reply-lines.md`, and `dm-text.md` start blank.
