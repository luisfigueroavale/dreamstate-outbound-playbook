# Contributing

Run the checks from this folder before you open a pull request.

```sh
npm install
npm run cards
npm run check
npm test
npm run demo
```

`npm run check -- --strict` needs `.banned-terms.local` on the machine. Do not commit that file.

Do not commit `brand.local/`, `audience.local/`, `settings.local/`, `data/`, `output/`, `work/`, or any key.

Do not send, enroll, post, schedule, or spend from a pull request. v1 is offline. A paid step still says dry_run first, quote, wait for the owner's yes on that item.

No em dash and no en dash. Dreamstate brand only.
