# Start here

Read this, then [quickstart.md](quickstart.md).

1. Install the CLI with `npx @trydreamstate/cli install` and sign in in the browser. The server is the URL in `.mcp.json`. Do not paste a key.
2. Run `npm run demo` and read the holds.
3. Run `run-free-quickstart` from Codex or Claude Code.
4. Copy `settings/` to `settings.local/` and fill the blank files with the agent.
5. Run `check-email-stack`.
6. Pick one play. Run `npm run plan-install`. Nothing has run.
7. Stop. Nothing has been sent or spent.

Codex is the preferred agent. Claude Code follows `CLAUDE.md`, which is the same text as `AGENTS.md`.
