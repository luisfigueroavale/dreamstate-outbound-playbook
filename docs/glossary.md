# Glossary

**Hold.** A row we will not act on, with a plain reason. Unknown is a hold.

**Touch.** One person, one post, one kind, and one reaction. A comment has a blank reaction. The same reaction twice is one touch.

**Tier.** 1, 2, 3, or hold, from `settings/tiers.json`. Tier 1 is the owner's own note. Tier 2 can become a draft sequence. Tier 3 is not a draft.

**Queued.** The only status `integrations.sync` returns. It is not proof the CRM accepted the row.

**Working default.** A number shipped so the demo can run. Change it after a learning note and a yes.

**To-check.** A number this repo does not pretend the rules page stated.

**Yes on that item.** Approval of one named object: one sync, one reply text, one import, one enable. A yes on a different object does not carry over.
