# Dreamstate skills

This repo does not copy the Dreamstate skills. They live in the workspace and in [dreamstate-plugins](https://github.com/luisfigueroavale/dreamstate-plugins). On 2026-11-22, `whoami` listed these ids. Load the same id `skills_list` returns.

| Job | Dreamstate skill | This repo |
| --- | --- | --- |
| Warm people from posts | `dreamstate-linkedin-warm-signals` | `roll-up-post-engagers` covers many posts and links to the funnel for one post |
| CRM records | `dreamstate-crm` | `route-inbound-form` |
| Mailbox health | `dreamstate-deliverability` | `check-email-stack` grades free reads |
| Workflows | `dreamstate-workflows` | `install-automation` stops at a disabled import |
| What to run next | `dreamstate-blueprints` | The notes in `plays/` are this repo's own pages |
| Social posts and replies | `dreamstate-social` | `share-on-comment-keyword` previews and waits |
| Sequences | `dreamstate-outreach` | Drafts only, until a separate yes |
| Company context | `dreamstate-knowledge` | `set-up-playbook` reads it and does not paste it |

A skill teaches judgement. It does not grant a send.
