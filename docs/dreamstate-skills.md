# Dreamstate skills

This repo does not copy the Dreamstate skills. They live in the workspace and in [dreamstate-plugins](https://github.com/luisfigueroavale/dreamstate-plugins). `skills_get` takes the bare id. On 2026-11-22, whoami listed prefixed ids such as `dreamstate-crm` and `dreamstate-deliverability`. Load the id `skills_list` returns. Do not guess if the two differ.

| Job | Dreamstate skill | This repo |
| --- | --- | --- |
| Warm people from posts | `linkedin-warm-signals` | `roll-up-post-engagers` covers many posts and links to the funnel for one post |
| CRM records | `crm` | `route-inbound-form` |
| Mailbox health | `deliverability` | `check-email-stack` grades free reads |
| Workflows | `workflows` | `install-automation` stops at a disabled import |
| Plays | `plays` | Not a substitute for the notes in `plays/` |
| Social posts and replies | `social` | `share-on-comment-keyword` previews and waits |
| Sequences | `outreach` | Drafts only, until a separate yes |
| Company context | `knowledge` | `set-up-playbook` reads it and does not paste it |

A skill teaches judgement. It does not grant a send.
