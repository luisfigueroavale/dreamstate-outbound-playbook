# Two ways to run

The Dreamstate app, or Codex and Claude Code through the MCP and the CLI. The rows live in the workspace either way. This repo does not keep a second copy of them.

The app is where you look at a worksheet, a run, an approval, and spend. The paths are in [where-to-look.md](where-to-look.md).

Codex is the preferred agent for the skills in this folder. Claude Code reads `CLAUDE.md`. Both use the one server in `.mcp.json`. Sign in in the browser. Do not paste a key.

`npm run demo`, `npm run quickstart`, `npm run cards`, `npm run plan-install`, and `npm run grade-stack` stay on this machine. They do not call Dreamstate.
