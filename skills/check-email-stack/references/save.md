# Save

## Inputs

Write work/email-stack.json with the raw reads and the as_of timestamp. work/ is git-ignored.

## Call

No Dreamstate call. npm run grade-stack can grade a saved file. The sample file is examples/sample-week/stack.json.

## Show the owner

The path you wrote.

## Failure cases

You commit the file. Do not. It can contain mailbox addresses.
