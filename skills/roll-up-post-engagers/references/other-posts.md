# Posts that are not yours

## Inputs

Only when the post is not one of the sender's own. The source card is source.engaged_with_account at 1 credit a row.

## Call

This is a paid source. dry_run first, quote, wait for the owner's yes on that item. The credit ceiling for the run is required. Working default 50.

## Show the owner

The row count and the quoted credits. Own-post harvest stays at 0.

## Failure cases

You bill an own post on this source. Do not. Own posts use harvest.
