# Offline demo

## Inputs

No Dreamstate params. npm run demo reads examples/sample-week/week.mjs.

## Call

The script writes output/demo/report.md and refreshes examples/sample-week/report.md. Credits stay 0.

## Show the owner

The summary table: forms, syncs proposed, touches, people, tiers, replies previewed, holds, credits 0, sent 0. Read one hold out loud so the reason is visible.

## Failure cases

The report does not match a fresh run. Fix the fixture or the function. Do not hand-edit the report.
