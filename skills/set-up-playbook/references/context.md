# Company Context

## Inputs

purpose outreach, or omit purpose for company context. brain_claim_limit can be 0 when you only need to know the pages exist.

## Call

dreamstate tools run knowledge.context.resolve after tools_get. Free read. Live is the mode, because a read has no dry run.

## Show the owner

Whether product, ideal customer, and tone pages are present. Quote a page only when the owner asked to see it, and do not write it into the repo.

## Failure cases

A page is thin or missing. Stop the play that needed it.
The read is truncated. Say so. Do not treat the missing tail as empty.
