# Workspace

## Inputs

No params. Call whoami first. The owner for this public repo uses workspace 0a13cecd-d194-46e5-94cc-328825aef631 when that is the one they named. If settings.local names a different id, that file wins after the owner wrote it.

## Call

MCP whoami. It is free. If the response lists more than one workspace, ask which one and stop. Do not read another workspace to compare.

## Show the owner

The workspace name, the id, and whether a score rubric and Company Context pages are present. Do not paste the page bodies into the chat log you commit.

## Failure cases

Another workspace is active. Stop.
A whoami error. Stop. Do not guess the id.
The rubric is missing. Say so. Do not invent scores.
