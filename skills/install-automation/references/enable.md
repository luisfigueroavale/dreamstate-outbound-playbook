# Enable is separate

## Inputs

workflow_ids is an array of 1 to 25 workflow ids. This skill does not call it as part of import.

## Call

workflow.workflows.enable is 0 credits and external. It can refuse when the 30 day action projection is over the allowance. Dry run still refuses an unsustainable schedule and does not write. A yes here is a standing action.

## Show the owner

If the owner asks, show the projection the dry run returns. Otherwise stop after import.

## Failure cases

Calling enable in the same breath as import. Do not. A schedule on the engager rollup is also its own yes.
