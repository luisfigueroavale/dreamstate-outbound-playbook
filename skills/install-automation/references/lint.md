# Lint

## Inputs

kind workflow and the same document. Read severity, not only a valid flag.

## Call

workflow.automations.lint. Free read. A blocking node_blocker_unmet is a missing prerequisite. A node_blocker_unknown means the readiness read failed. Those are different.

## Show the owner

Each blocking finding in plain words. A clean lint is still not an enable.

## Failure cases

message copy is missing or a token will not resolve. Fix the graph or the settings file. Do not import over it.
