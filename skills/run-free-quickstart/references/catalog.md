# Engaged sources

## Inputs

query: engaged. You can also pass kinds source.

## Call

tables.findable_catalog.list. Free. Read pricing.minimum_credits and pricing.maximum_credits and the unit.

## Show the owner

Each matching source id and its per-row or per-run price. A null maximum is unconfirmed, not zero.

## Failure cases

The catalog is empty. Say so. Do not fill the gap with a remembered price.
