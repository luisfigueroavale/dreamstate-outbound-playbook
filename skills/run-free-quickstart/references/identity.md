# Identity

## Inputs

No params on whoami. Expected workspace id from settings.local, or 0a13cecd-d194-46e5-94cc-328825aef631 when the owner has not written one.

## Call

MCP whoami. Stop on a mismatch. npm run quickstart prints this list and does not call the network.

## Show the owner

Workspace id and name. Say the check has not spent anything yet, because you have not made a paid call.

## Failure cases

Wrong workspace. Stop. Do not continue the list in the other workspace.
