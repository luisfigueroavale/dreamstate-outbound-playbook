# Readiness

## Inputs

whoami returns senders, mailboxes, worksheets, and knowledge page flags. Use the counts it returns.

## Call

Free. If linkedin_senders is 0, do not suggest the engager rollup or the keyword share. If mailboxes is 0, the email stack grader still runs, and a send is not available.

## Show the owner

The counts, and which play they rule out. A missing ideal customer page rules out a fit score until knowledge is filled.

## Failure cases

More than one workspace. Stop before you suggest a play.
